# Deprecated / Obsolete Components Pending Removal

This register tracks components marked **obsolete** (rather than deleted) per the Solution Architect agent's [Non-Breaking Change & Deprecation Management](../.github/agents/solution-architect.agent.md#non-breaking-change--deprecation-management) approach, pending a planned, batched clean-up.

- Add a row here whenever a component is marked obsolete (e.g. deactivated, set to Inactive, or admin/support-scoped) instead of deleted.
- Before adding an entry, confirm all dependencies/consumers of the component have been removed or migrated.
- Remove the row once the component is actually deleted as part of a batched clean-up activity.
