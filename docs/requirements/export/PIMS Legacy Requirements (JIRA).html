*AC-1: Initial Conditions*
On deployment, PIMS has two Auto-number counters: "Import Record Priority 2 Counter" and "Import Record Priority 2 Quota Counter", both created with value of 0.

{quote}If the "Import Record Priority 2 Quota Counter" counter is non-zero, it means that too little cases are currently scheduled for a Post Import Check.
For example, Risk Level of some of P2 cases scheduled for a Post Import Check were re-assessed and other Import records need to be scheduled for a Post Import Check instead.
The "Import Record Priority 2 Counter" counter enables PIMS to skip Import Records that that do not need a Post Import Check.
If it is negative, it means that too many Post Import Checks are currently scheduled for a Post Import Check.
For example, Risk Level of multiple P2 Import Records not scheduled for a Post Import Check were re-assessed.{quote}

*AC-2: Changing Risk Level*

Applies when the Risk Level on an Import Record is set or changed.
There is no difference if the Risk Level (P1/P2/P3) is determined automatically by the system or set by the user.

*WHEN* the Risk Level was changed from:

* Non-P2 to non-P2: no action will be taken.
* Non-P2 to P2: PIMS will determine if inspection is required - see: AC-3.
* P2 to non-P2: PIMS will adjust counters to maintain the ratio of inspections - see: AC-4.

*AC-3 - Determining if a Post Import Check is Required*

Applies when an Import Record Risk Level is set to P2 from any other status.

If the "Import Record Priority 2 Quota Counter" is greater than zero:

* Decrease the "Import Record Priority 2 Counter" counter by 1.
* {color:#ff5630}The case is flagged for inspection as per "10% P2-Case" rule.{color}

If the "10% P2-Case-Quota" equals zero (or less):

* The "10% P2-Case" counter is incremented by 1.

If the "10% P2-Case" counter was incremented above the "10% P2-Case" limit (of 10):

* The "10% P2-Case" counter is set to 0.
* The case is flagged for inspection as per "10% P2-Case" rule.

*AC-4 - Adjusting to maintain inspection ratio*

Applies when a case risk was a P2 and has been changed to any other status.

If the case was flagged for inspection as per "10% P2-Case" rule.

* The "10% P2-Case-Quota" counter is incremented by 1.
This will result in the next case flagged as P2 being inspected (in place of the changed one), bringing the number of inspected cases to the right level.

If the case was not flagged for inspection as per "10% P2-Case" rule.

* The "10% P2-Case" counter is decremented by 1.
This will result in the next case flagged as P2 not being inspected (in place of the changed one), maintaining the level of cases not inspected. The counter can go into negative values.

If the "10% P2-Case-Quota" is grater than zero and "10% P2-Case" counter is negative by more than "10% P2-Case" limit (-10 or more):

* The "10% P2-Case-Quota" is decreased by 1.
* The "10% P2-Case" is increased by the limit amount.
This will adjust the inspection ratio after many cases are moved from P2 in bulk. This adjustment is to help balance the inspect-to-not-inspect ratio faster.
