# Assumptions and Constraints

## Assumptions

| ID      | Assumption                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     | Source                                                                                                                                                                                                                                             |
| ------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ASM-001 | PIMS is built on Microsoft Dynamics 365 (Model-Driven App) and Azure Integration Services. All requirements assume these platforms remain in use.                                                                                                                                                                                                                                                                                                                                                                              | Across all stories                                                                                                                                                                                                                                 |
| ASM-002 | TRACES Classic provides ITAHC and DOCOM data in a structured JSON format that can be consumed by Azure Logic Apps/Functions. Field mapping details remain to be agreed separately, so attribute-level traceability is incomplete until the schemas behind IMTA-6598, IMTA-6599, IMTA-6600 and IMTA-6601 are confirmed. | IMTA-6598, IMTA-6599, IMTA-6600, IMTA-6601 |
| ASM-003 | IPAFFS provides Importer Notifications in JSON format via a push to an Azure Service Bus Queue. The implemented entity is Importer Notification, even where some legacy labels continue to use the term Import Notification.                                                                                                                                                                                                                                                                                                   | IMTA-5864, IMTA-7201                                                                                                                           |
| ASM-004 | The Country reference data entity is sourced from the existing Exports solution (Microsoft Customer engagement) and is available for import into the EU Imports solution.                                                                                                                                                                                                                                                                                                                                                      | IMTA-5915                                                                                                                                                                                        |
| ASM-005 | Commodity Type reference data is sourced from the existing Defra Exports D365 solution and is available for import into the EU Imports solution.                                                                                                                                                                                                                                                                                                                                                                               | IMTA-5916                                                                                                                                                                                        |
| ASM-006 | All caseworker users are authenticated via Azure Active Directory (Entra ID) with Dynamics 365.                                                                                                                                                                                                                                                                                                                                                                                                                                | General                                                                                                                                                                                                                                            |
| ASM-007 | TRACES service account auto-creation of ITAHC/DOCOM records uses a dedicated service principal whose identity is distinguishable from human users. This is required for the auto-create Import Record logic (IMTA-6600, IMTA-6601).                                                                                                                                                                                        | IMTA-6600, IMTA-6601                                                                                                                           |
| ASM-008 | The Devolved Office field on an Import Record reflects Scottish, Welsh and English routing. Geographic team assignment is configurable using out-of-the-box D365 Team records.                                                                                                                                                                                                                                                                                                                                                 | IMTA-5863, IMTA-6661                                                                                                                           |

| ASM-010 | Inspection Coverage Rule thresholds (e.g. "every 50th P3 record" ≈ 2%) are configurable by Dynamics 365 System Administrators. The mechanics of export (Advanced Find export, custom report or Power BI) are not specified in the source stories and must be confirmed.                                                                                                                                                                                                                              | IMTA-6354                                                                                                                                                                                        |

## Technical Constraints

| ID      | Constraint                                                                                                                                                                                                       | Source                                                                                                                                                                                                                                                                                                          |
| ------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| CON-001 | PIMS is constrained to Microsoft Dynamics 365 Model-Driven App patterns (Plugins, Custom Workflow Activities, Business Rules, JavaScript Web Resources). Custom portals or standalone services are out of scope. | Platform constraint                                                                                                                                                                                                                                                                                             |
| CON-002 | Business logic must be implemented as synchronous Plugins or Custom Workflow Activities for risk assessment rules to ensure data consistency on record save.                                                     | IMTA-5866, IMTA-5892, IMTA-5895 Solution notes                                                                                                            |
| CON-003 | Auto-number fields in Dynamics 365 cannot guarantee gapless sequences in all failure scenarios. The unique reference number (BR-022) and query number (BR-023) formats must account for this.                    | IMTA-6132, IMTA-6185                                                                                                                                                                                        |
| CON-004 | The D365 audit log must be enabled at both organisation and entity level before audit requirements (NFR-AUD-001, NFR-AUD-002) can be satisfied.                                                                  | IMTA-5986, IMTA-6128                                                                                                                                                                                        |
| CON-005 | Dashboards and reports are built using native D365 Charts, Views and Dashboards. Power BI or custom reporting tools are not referenced in the source stories.                                                    | IMTA-6340, IMTA-6341, IMTA-6343, IMTA-6344, IMTA-6372 |

## Organisational Constraints

| ID      | Constraint                                                                                                                                                                                                      | Source                                                                                                                                                                                |
| ------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ORG-001 | Inspection Coverage Rule thresholds (2% P3, 10% P2) are set by Defra policy. PIMS must implement them as configurable values but must not allow business users below System Administrator level to change them. | IMTA-5891 AC-2                                                                                                                      |
| ORG-002 | The EU Imports Business Rules Admin role is responsible for maintaining Commodity Risk Levels, Gold/Bronze Commodities and the unique reference number prefix. Changes must be auditable.                       | IMTA-5865, IMTA-5888, IMTA-6132 |
| ORG-003 | Geographic team routing (Scotland, Wales, England) must reflect the actual organisational structure of the IRMS team and must be maintained in D365 Team records.                                               | IMTA-5863                                                                                                                           |

## External System Constraints

| ID      | Constraint                                                                                                                                                                                           | Source                                                           |
| ------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------- |
| EXT-001 | PIMS consumes messages from TRACES Classic and IPAFFS; it does not push data back to these systems. PIMS is a read-only consumer of external notifications.                                          | Inferred from all integration stories                            |
| EXT-002 | IPAFFS message delivery is asynchronous and event-driven (status change trigger: Submitted, Amended, Cancelled). PIMS must handle all three statuses as create-or-update operations.                 | IMTA-5864 AC-1 |
| EXT-003 | TRACES Classic sends notifications by email to the CIT team. The integration intercepts this mechanism and routes data via Azure Service Bus. The email channel must remain available as a fallback. | IMTA-6598 AC-1 |
