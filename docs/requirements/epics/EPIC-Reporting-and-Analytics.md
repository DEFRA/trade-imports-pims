# Epic: Reporting and Analytics

## Purpose

Provide caseworkers, team leaders and data analysts with operational dashboards and exportable reports to monitor EU imports activity and demonstrate Defra policy compliance.

## Business Value

- Real-time operational visibility replaces manual data aggregation.
- Policy compliance (2% P3, 10% P2 inspection coverage) can be demonstrated and audited.
- The Farming Analysis and Evidence Team (FAET) can produce weekly reports for cross-department sharing without bespoke tooling.

## Capability Description

PIMS provides five operational dashboards and two reporting capabilities:

| Dashboard / Report                       | Audience                                        |
| ---------------------------------------- | ----------------------------------------------- |
| EU Imports — Daily Huddle Stats          | Caseworkers (regional view)                     |
| EU Imports — Daily Stats                 | Caseworkers (today's activity)                  |
| EU Imports — Daily IRMS Stats            | Caseworkers (IRMS-specific view)                |
| EU Imports — Border Control Metrics      | Caseworkers (monthly scanning check compliance) |
| EU Imports — APHA Border Control Metrics | Caseworkers (dog/cat/ferret check compliance)   |
| FAET Weekly Report                       | Data Team / FAET                                |
| Inspection Coverage Audit Report         | Team Leaders / Data Team                        |
